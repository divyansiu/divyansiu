# Quiet Systems — visual system

- Background: `#0B1014`
- Surface: `#11181D`
- Primary accent: `#75E6C1` (muted mint)
- Secondary accent: `#D89B63` (warm copper)
- Main text: `#F3F5F7`
- Secondary text: `#AEB8BE`
- Muted text: `#68747B`

The visual language is intentionally restrained: graphite surfaces, a single cool accent, a small warm counter-accent, fine grid lines, and signal-like geometry.
